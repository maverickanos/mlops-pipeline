# Data Directory

This directory contains datasets used in the MLOps pipeline.

## Structure

- `sample_data.py` - Script to generate sample datasets (breast_cancer, iris)
- `breast_cancer_train.csv` / `breast_cancer_test.csv` - Generated by sample_data.py
- `iris_train.csv` / `iris_test.csv` - Generated by sample_data.py

## Usage

```bash
python data/sample_data.py
```

## Datasets

- **Breast Cancer Wisconsin** - 569 samples, 30 features, binary classification
- **Iris** - 150 samples, 4 features, 3-class classification

The pipeline uses sklearn's built-in datasets by default via `pipeline.data_preprocessing.load_dataset()`.
